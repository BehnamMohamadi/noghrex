# ساخت ادمین اولیه

در پوشه پروژه اجرا کنید:

```sh
npm run admin:create
```

شماره همراه مدیر پرسیده می‌شود. یا مستقیم وارد کنید:

```sh
npm run admin:create -- --phone 09123456789
```

دستور به دیتابیس `MONGODB_URI` در `.env` وصل می‌شود؛ MongoDB باید روشن و دارای پشتیبانی تراکنش باشد. برای دیتابیس محلی پروژه ابتدا `npm run db:local` را اجرا کنید.

برای حساب جدید رمز تصادفی ساخته و یک بار در ترمینال نمایش داده می‌شود؛ آن را ذخیره کنید. برای تعیین رمز دلخواه، متغیر محیطی `ADMIN_PASSWORD` را پیش از اجرا تنظیم کنید (حداقل ۱۲ کاراکتر، حداکثر ۷۲ بایت). رمز در کد یا فایل تنظیمات نوشته نمی‌شود و در دیتابیس با bcrypt هش می‌شود.

ورود از `/admin/` با شماره همراه و رمز انجام می‌شود. نقش `admin` به بخش‌های مدیریتی فعلی از جمله کاربران، محصولات، موجودی، قیمت‌ها، سفارش‌ها، واریز و برداشت، بازپرداخت، احراز هویت و تنظیمات دسترسی دارد؛ قواعد مالی و اعتبارسنجی همچنان اعمال می‌شوند.

اجرای مجدد برای ادمین فعال، رمز را تغییر نمی‌دهد. حساب عادی یا غیرفعال ارتقا یا فعال نمی‌شود. ساخت حساب و کیف پول در یک تراکنش انجام می‌شود. این دستور داده نمونه یا موجودی مالی ایجاد نمی‌کند.
