# Customer visual assets

All production-referenced copies live in `public/customer/assets`. Original generated images remain in the Codex generated-images directory. The built-in imagegen tool was used (not the API/CLI fallback).

## Prompt set

- `silver-hero.png`: product-mockup; two floating photorealistic silver bullion bars, diagonal perspective, large main bar and smaller rear bar, brushed silver, beveled edges, crisp softbox reflections with deep teal accents, NOGHREX / 999.9 FINE SILVER engravings, fully visible clean silhouettes, true transparent alpha background, no UI or backdrop. Intended to extend outside a dark teal website card with CSS parallax.
- `brand.png`: edit/extract the user's supplied angular folded N monogram. Preserve the geometric folded-ribbon identity; refine edges, recolor shadow faces teal #167B75 and navy #112535, retain silver/pearl front faces. Remove all background and source-image text. Transparent output. Website wordmark is accessible HTML text rather than baked into the asset.
- `jewelry-delicate.png`: premium editorial product-mockup; fine slender silver necklace with one small clear gemstone pendant and two very thin silver stacking rings; off-white architectural plinth, cool pearl backdrop, understated softbox light, airy asymmetrical composition. No chunky cuffs, heavy chain, gold, text or logo.
- `jewelry-bold.png`: premium editorial product-mockup; sculptural polished silver open cuff and silver ring, brushed/mirror finishes, pearl background, subtle teal reflections, soft light, no gold/text/UI. The user first rejected it for the main direction, then explicitly requested including the bold style as well; it is used only in the bold collection editorial card.

The images are editorial illustrations, not assertions about actual inventory, certification or metal composition. Actual products are read from the backend, and their images are supplied by the store administrator.

## Motion

`silver-motion.webm`, `silver-motion.gif`, `silver-motion-poster.png` are original code-native 3D geometry renders generated by `scripts/build-customer-motion.py` using Pillow/numpy. They contain two rotating metallic loop meshes, perspective, lighting and orbital guides. VP8 frames are packaged in WebM; no third-party footage or music is used. The loop lasts four seconds. GIF is 320×210; WebM is 640×420.

The site pauses videos outside the viewport or when the document is hidden; respects reduced-motion and provides an explicit motion toggle. The GIF becomes a static poster in reduced-motion mode. Hero parallax is disabled for reduced-motion and touch input.

The font is the project's local Vazirmatn variable font, served from `/admin/fonts/`, with its bundled OFL license.
